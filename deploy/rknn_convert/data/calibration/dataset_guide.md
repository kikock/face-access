# RKNN 量化校准数据集准备指南

在将 ONNX 转换为 RKNN INT8 静态量化模型时，RKNN-Toolkit2 需要通过一段真实的输入样本（校准数据集）来统计各层网络激活值的动态范围（Min-Max 截断、KL 散度或 MMSE 均方误差），从而生成精确的定点缩放因子（Scale 与 Zero-point）。

---

## 1. 校准样本数量建议

- **样本规模**：建议准备 **100 ~ 300 张** 具有代表性的图片。
- **场景分布**：
  - 覆盖真实场景下的正常光照、微逆光、侧脸、微表情、戴眼镜及不同肤色。
  - 严禁全部使用纯黑、纯白或全相同图像，会导致激活值统计退化。

---

## 2. 三个模型的校准列表格式

RKNN 使用纯文本列表文件（`dataset.txt`），每一行记录一张校准图片的绝对路径或相对路径：

### 2.1 检测模型校准集 (`detector_dataset.txt`)
- **内容要求**：未裁剪的原图，包含至少 1 张清晰人脸。
- **尺寸**：分辨率建议与实际摄像机一致（如 1080P 或 720P），或者直接预处理成 320x240 RGB 图像。

### 2.2 关键点模型校准集 (`landmark_dataset.txt`)
- **内容要求**：紧贴人脸框并略微外扩 10% 的灰度裁剪图。
- **尺寸**：预先缩放到 64x64 单通道灰度图像。

### 2.3 特征提取模型校准集 (`feature_dataset.txt`)
- **内容要求**：经过平台标准 5 点仿射变换对齐后的人脸切片（BGR 格式）。
- **尺寸**：严格 128x128 像素。

---

## 3. 快速自动生成测试校准集

若本地尚未准备现场图片，可运行辅助构建脚本从 `backend/data/` 或合成随机噪声数据进行前置语法验证：
```bash
python generate_dummy_calibration.py
```
> **注意**：使用随机噪声校准仅供测试转换流程与算子支持，**严禁用于生产部署**！生产环境必须采集真实人脸切片。
